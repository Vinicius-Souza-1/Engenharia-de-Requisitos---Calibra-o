# Engenharia de requisitos — certificados de calibração

Estudo acadêmico de ADS organizado para o portfólio de Vinicius Itamar de Souza. Esta versão demonstrativa foi adaptada de uma especificação de requisitos elaborada durante o curso.

## Problema estudado
O preenchimento manual de certificados a partir de planilhas pode provocar retrabalho, campos incompletos e dificuldade para consultar o histórico.

## Proposta
Documentar um sistema que importe medições, valide informações, permita revisão e gere certificados aprovados em PDF.

## Conteúdo
- `docs/requisitos.md`: funcionalidades, qualidades, prioridades e critérios de aceite.
- `docs/escopo.md`: usuários, limites, fluxo e etapas propostas.

Este repositório contém documentação; o software não foi implementado. As regras são propostas acadêmicas sujeitas à validação dos usuários. Não contém planilhas internas, marcas, medições ou certificados de uma empresa real. Não representa aprovação ou vínculo oficial com uma organização.

## Aprendizados
Identificação de necessidades, distinção entre requisitos funcionais e não funcionais, priorização e escrita de critérios verificáveis.

## Origem
Versão demonstrativa resumida a partir da especificação acadêmica de setembro de 2026. A publicação usa exemplos genéricos e não inclui o documento corporativo de referência.
